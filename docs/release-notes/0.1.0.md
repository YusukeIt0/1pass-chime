First release.

- Plays a sound when 1Password asks for approval (SSH agent, `op` CLI sign-in), and repeats it every few seconds until you answer, or plays once.
- The menu bar icon turns red while a request is waiting.
- Built-in chime, macOS alert sounds, or your own audio file, with volume.
- Stop the sound for the current request, pause sounds, open at login.
- No permissions needed; nothing is read from 1Password.
- 13 languages.

Builds are not notarized by Apple yet; the installer checks the checksum and code signature.
